# Crew Notes Lab 13

1. **Use case**: Аналіз новин на наявність фейків та маніпуляцій.
2. **Агенти**: Triager, Extractor, Reviewer, Fallback.
3. **Ролі**: 
   - Triager: Маршрутизація та оцінка складності.
   - Extractor: Вилучення структурованих даних (твердження, джерела, тон).
   - Reviewer: Перевірка на галюцинації (вигадані джерела) та консистентність.
   - Fallback: Виправлення JSON на основі зауважень Reviewer.
4. **Правила делегування**: Triager -> Extractor -> Reviewer. Якщо Reviewer == 'repair_needed', викликається Fallback.
5. **Що перевіряє Reviewer**: Відповідність джерел тексту, валідність маркерів, тон.
6. **Коли спрацьовує fallback**: Коли Reviewer знаходить галюцинації або пропущені поля.
7. **Покращення порівняно з single-agent**: Абсолютна стійкість до галюцинацій завдяки етапу самоперевірки та ремонту.
8. **Де підхід зайвий**: Для простих новин (чистий фактаж), де Extractor справляється з першого разу.
9. **Помилки, що залишилися**: Високий відсоток активації Fallback свідчить про необхідність оптимізації базового промпту Extractor.
10. **Що б фіксили далі**: Тюнінг Extractor (Few-shot prompting), щоб знизити навантаження на Fallback агента.

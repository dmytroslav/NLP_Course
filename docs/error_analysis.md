# 🔍 Error Analysis (Аналіз помилок)

У цьому документі зібрані найпоказовіші приклади помилок системи на різних етапах розробки, а також архітектурні рішення, які були застосовані для їх виправлення. Це дозволило еволюціонувати від базової ML-моделі до гібридної Two-Tier архітектури.

---

## 1. Проблема "семантичної сліпоти" та шум у даних (Baseline ML Error)
Базова статистична модель була вразливою до суржику та нестандартного форматування.

* **Category:** Data noise / Domain shift
* **Input:** *"ШОК!!! ЗСУ пашлі в наступленіє, терміново всім дивитись!!!"*
* **Expected Label:** Fake
* **Predicted Label (Baseline):** True (модель пропустила маніпуляцію).
* **Fix (Tier 1):** Перехід від TF-IDF на рівні слів (Word n-grams) до символьних n-грам (Char n-grams 3-5). Це дозволило `LinearSVC` вловлювати патерни клікбейту незалежно від орфографії.

## 2. Проблема витягнення специфічного контексту (NER Error)
Стандартні переднавчені NER-моделі погано працюють з Out-of-Domain лексикою.

* **Category:** Missed entities
* **Input:** *"Сьогодні вночі сили ППО та підрозділи 93-ї ОМБр успішно відбили атаку."*
* **Expected Entities:** `["ППО", "93-ї ОМБр"]`
* **Predicted Entities (Base spaCy):** `[]` (порожній список).
* **Fix (Tier 1 Information Extraction):** Розробка кастомних `regex`-патернів та інтеграція `EntityRuler` для точного витягнення українських військових абревіатур та специфічної термінології.

## 3. Проблема форматування LLM-агента (Generation Error)
При ізольованих запитах великі мовні моделі часто порушують синтаксис JSON.

* **Category:** Invalid JSON / Hallucinated fields
* **Input:** Текст новини для глибокого семантичного аналізу.
* **Expected Output:** `{"label": "fake", "reasoning": "Маніпуляція фактами"}`
* **Predicted Output (Single-shot LLM):** `Here is your result: {"label": "fake", "reasoning": "Маніпуляція фактами"}` (зайвий текст перед дужками ламає парсинг).
* **Fix (Tier 2):** Впровадження архітектури **Stateful Flow з repair loop**. При виникненні помилки валідації (Validation Error) система автоматично робить повторний запит агенту з вказівкою на порушення формату, гарантуючи 100% цілісність даних на виході.

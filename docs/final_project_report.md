# Final Project Report: Fake vs True Classification on Ukrainian News

## 1. Актуальність та опис даних
Задача автоматичного виявлення маніпуляцій та фейків є критично важливою для українського інфопростору. У якості даних використано корпус новин (`processed_v2.csv`). 
* **Особливість даних:** Наявний дисбаланс класів (~76.7% True проти 23.3% Fake).
* **Тип текстів:** Новини, офіційні зведення, клікбейт та пропагандистські матеріали.

## 2. Архітектура рішення (Pipeline)
Для досягнення максимальної продуктивності розроблено **Dual Pipeline**, який складається з наступних етапів:

1. **Preprocessing (ЛР2, ЛР3):** Очищення від спецсимволів, нормалізація пробілів, лематизація.
2. **Classification (ЛР7):** Векторизація через TF-IDF (analyzer='char_wb', ngram_range=(3, 5)) та класифікація за допомогою LinearSVC із параметром `class_weight='balanced'` для нівелювання дисбалансу.
3. **Information Extraction (ЛР10):** Використання spaCy з кастомними правилами (EntityRuler + Regex) для виділення організацій (ЗСУ, ППО), локацій та фінансових маркерів.

## 3. Порівняння Baseline vs Final System
* **Baseline (ЛР6 - Logistic Regression + Word n-grams):**
  * Accuracy: ~0.89
  * Macro-F1: ~0.85
* **Final System (ЛР7 - LinearSVC + Char n-grams):**
  * Accuracy: **0.9236**
  * Macro-F1: **0.8903**

**Висновок:** Перехід від слів до символьних n-грам дозволив системі краще "ловити" суржик, одруківки та специфічні закінчення, характерні для емоційних маніпуляцій та пропаганди, а SVM забезпечив краще розділення класів.

## 4. Error Analysis (Аналіз помилок)
Під час тестування виявлено фундаментальне обмеження класичного машинного навчання (TF-IDF). Система чудово відфільтровує клікбейт, але помиляється на семантичних фейках, написаних офіційною мовою.

**Приклади помилок (False Positives - розпізнано як True, але це Fake):**
1. *Input:* "Росіяни захопили ще одну область"
2. *Input:* "Зеленський віддав всі окуповані території заради миру"
3. *Input:* "Україна програла війну"

**Категорія помилки:** Domain Shift / Словниковий перетин.
**Причина (Why it fails):** TF-IDF спирається на статистику слів. Слова "Зеленський", "війна", "Україна" у тренувальному датасеті зустрічаються переважно в достовірних зведеннях. Оскільки алгоритм не розуміє змісту речення, він бачить високочастотну "правдиву" лексику і дає хибний вердикт, не помічаючи фактологічної брехні.

## 5. Подальші кроки
Якби на розробку був ще один тиждень, я б сфокусувався на таких покращеннях:
1. **Для класичного ML:** Застосування SMOTE для боротьби з дисбалансом класів на етапі тренування та налаштування кастомного порогу ухвалення рішень (Thresholding) для максимізації Recall для класу Fake.
2. **Для семантичного розуміння:** Перехід від розріджених векторів (TF-IDF) до щільних (Word Embeddings / BERT-like моделей), щоб модель розуміла не лише частоту слів, але й суть (наприклад, що слово "програла" біля слова "Україна" змінює тональність новини на пропаганду).

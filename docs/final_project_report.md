# Final Project Report: Fake vs True Classification on Ukrainian News

## 1. Актуальність та опис даних
Задача автоматичного виявлення маніпуляцій та фейків є критично важливою для українського інфопростору. Використано корпус новин (`processed_v2.csv`), що містить офіційні зведення, клікбейт та пропагандистські матеріали. Наявний дисбаланс класів (~76.7% True проти 23.3% Fake).

## 2. Архітектура рішення (Dual Pipeline)
Проєкт побудовано на **Two-Tier Architecture**:
1. **Tier 1 (ЛР1-ЛР10):** Очищення тексту, лематизація, векторизація через TF-IDF (char n-grams 3-5) та класифікація за допомогою `LinearSVC(class_weight='balanced')`. Паралельно працює гібридний NER (spaCy) для витягнення сутностей (організації, локації, фінанси).
2. **Tier 2 (ЛР11-ЛР14):** Інтегрований Stateful Flow на базі LLM (`llama-3.1-8b-instant` через Groq API). Використовується сувора JSON-схема та механізм `repair loop` для автовиправлення помилок парсингу моделі.

## 3. Порівняння метрик та Baseline
* **Baseline (Logistic Regression + Word n-grams):** Accuracy: ~0.89 | Macro-F1: ~0.85
* **Final Tier 1 (LinearSVC + Char n-grams):** Accuracy: **0.9236** | Macro-F1: **0.8903**
* **Final Tier 2 (Agentic Flow):** 100% генерація валідного JSON контракту.

## 4. Error Analysis та вирішення проблем (Domain Shift)
Під час тестування класичного ML виявлено проблему: система чудово відфільтровує клікбейт, але помиляється на фактологічних фейках (наприклад: *"Зеленський віддав всі окуповані території заради миру"*).
* **Причина:** TF-IDF спирається на статистику слів. Слова "Зеленський", "війна", "території" часто зустрічаються в правдивих новинах, тому алгоритм видавав хибний вердикт `True`.
* **Рішення:** Запуск Tier 2. Передача таких текстів у Agentic Flow дозволила системі розуміти зміст повідомлення і відловлювати маніпуляції, з якими не впорався частотний аналіз.

## 5. Висновки
Інтеграція класичного ML (для швидкості та дешевизни) з LLM-агентами (для складного семантичного аналізу та обґрунтувань) є найбільш надійним підходом до побудови систем фактчекінгу.

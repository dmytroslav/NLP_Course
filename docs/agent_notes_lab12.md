# Agent Notes (Lab 12)

1. **Який use case обрано:** Fact-checking новин українського інфопростору (Fake/True класифікація).
2. **Який agent task:** Отримати сирий текст новини, перевірити джерело та наявність офіційних спростувань, винести фінальний вердикт.
3. **Які tools реалізовано:** `check_source_credibility` (база надійності ЗМІ), `get_official_fact` (база офіційних спростувань).
4. **Як агент вирішує, коли викликати tool:** На основі системного промпту (tool_choice="auto"). Агент аналізує наявність назв джерел або ключових тем (блекаут, мобілізація).
5. **Як логуються tool calls:** Через кастомний клас `ToolLogger`, який записує кожен виклик як окремий JSON-рядок (JSON Lines) із вказанням timestamp, task_id, input та output.
6. **Що tools реально покращили:** Усунуто галюцинації щодо політики видань (агент більше не вигадує статус "РИА Новости").
7. **Де tools були зайві або не допомогли:** На текстах із загальновідомими фактами (наприклад, "Київ - столиця") агент даремно витрачає токени на виклик бази фактів.
8. **Які помилки лишилися:** Проблема конфліктуючих тригерів (наприклад, маніпулятивна фраза "Офіційно від Трухи" плутає логіку агента).
9. **Що б ви фіксили далі:** Додати pre-routing шар, який відсіює загальновідомі факти від новин, щоб не витрачати ліміти API на інструменти.
